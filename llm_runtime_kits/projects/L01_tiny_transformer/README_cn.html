L01 从零实现并训练小型 Transformer

状态：已整理，未运行验证。
平台：Linux / Windows CPU。无 GPU 要求。内存估算：约 0.5–2 GiB（batch=8、seq=64、d=64，条件写在 config/train.json）。

目标

字符级分词 + 单层解码器，在 fixtures/corpus.txt 上最小化训练，理解 embedding、注意力、残差、CE loss、检查点。不是 GPT-4/Qwen 预训练。

依赖

environments/py310_linux 或 py312_linux（及 windows 对应目录）。本轮只下载 wheel，未建 venv。
