# 3 数据工程

多数闭源与多数开放权重模型的完整配比、过滤阈值、污染表是 **推测或未知**。下面只列公开文献里出现过的工序名称。

| 工序 | 公开确认的来源类型 | 本库态度 |
|---|---|---|
| 采集（网页、代码、书籍） | 技术报告概述 | 不保存网页抓取结果 |
| 清洗、去毒、PII | 报告定性描述 | 无原厂流水线 |
| 去重（MinHash 等） | 论文/博客常见 | 第三方方法，非某厂源码 |
| 质量过滤、配比 | 报告表格（若有） | 不编造比例 |
| 合成数据 | Phi、部分后训练论文 | 合成 ≠ 无污染 |
| 分词与打包（packing） | 训练框架 | L01 用极小合成语料 |
| 污染检测 | 评测论文常见 | 记录评测是否去污染 |
| 数据版本 | DVC 等工程实践 | L06 只做配置版本，无大数据湖 |

L01 的 `fixtures/corpus.txt` 是为理解打包而写的示意数据，**不是** 预训练语料。
